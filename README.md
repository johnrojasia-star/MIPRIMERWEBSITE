# FARMASUEÑOS — sitio web

Página de producto FARMASUEÑOS. Para desplegar la versión completa, subir `index.html` y la carpeta `img/` del paquete entregado, directamente a la raíz del repositorio.

## Archivos necesarios
- `index.html`
- `img/logo.webp`
- `img/producto.webp`
- `img/persona.webp`
- `img/anuncio.webp`
- `img/campana.webp`
- `img/detalle.webp`

## Publicación
Una vez subidos los archivos, activar GitHub Pages en Settings > Pages > Deploy from a branch > main / root.

**Nota:** Precio, condiciones de venta, información sanitaria y testimonios deben verificarse antes de publicar.
